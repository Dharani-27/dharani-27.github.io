  1. MASCOT: Analyzing Malware Evolution Through a Well-Curated Source Code Dataset

    Bojing Li, Duo Zhong, Dharani Nadendla, Gabriel Terceros, Prajna Bhandary, Raguvir S, and Charles Nicholas

    arXiv preprint arXiv:2512.00741, November 2025.

    A manually reviewed dataset of 6,032 malware source-code samples. It is used to study the size, quality, security, and dependencies of modern malware, and to trace how code reuse drives malware lineages.
